# Fountain Coach standards

These organization standards are referenced, not duplicated:

- [FCIS Publication and Source Policy](https://github.com/Fountain-Coach/.github/blob/main/docs/FCIS-Publication-and-Source-Policy.md) — **applies now**.
- [FCIS Security Architecture](https://github.com/Fountain-Coach/.github/blob/main/docs/FCIS-Security-Architecture-Briefing.md) — **applies now** to source and rights boundaries.
- RFC 0001 — four orthogonal layers (AGENTS, PLANS, Skills, external MCP/tool capability) — **applies now**.
- [FCIS-KIT 1.3](https://github.com/Fountain-Coach/.github/blob/main/docs/FCIS-KIT-Standard.md) — **conditional**, when publishing or consuming Fountain Coach Swift kits.
- [FCIS-AX](https://github.com/Fountain-Coach/.github/blob/main/docs/FCIS-AX-Standard.md) — **conditional**, when developing interactive UI.
- [FCIS-VRT](https://github.com/Fountain-Coach/.github/blob/main/docs/FCIS-VRT-Standard.md) — **conditional**, for visual product changes.
- [FCIS-AIC Preflight](https://github.com/Fountain-Coach/.github/blob/main/docs/FCIS-AIC-Preflight-RFC.md) — **conditional**, for on-device model functionality.

This is only a public documentation repository. The standards' non-applicability to present content must never be mistaken for permission to bypass them in later instrument code, installation or public-facing software. See FCIS_AUDIT.md.
