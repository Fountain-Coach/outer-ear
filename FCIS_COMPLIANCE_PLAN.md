# FCIS compliance plan

**Goal:** Keep the outer-ear public Git repository truthful, reproducible and privacy-safe.

1. **Publication gate.** Classify each artifact: public working document, approved public bios, private/unapproved personal record, or signed private agreement. Default to withholding unapproved personal material.
2. **Source gate.** SHA-256 originals, deduplicate identical uploads, retain exact bytes and one Markdown text transcription per published PDF. Link derivatives to originals.
3. **Instruction boundary.** AGENTS = behavior; PLANS = intent; mirrored skills = method; MCP/tools = capabilities. Never create Actions/workflows.
4. **Claims gate.** Separate alpha, accepted artistic brief, application submitted, grant decision, physical prototype, software admission, and public premiere.
5. **Future runtime gate.** Before coding: history-first audit of FCIS-owned MIDI2/Teatro instruments and their versions, separate safety and accessibility tests, visual regressions if UI, AI preflight if models. No new execution ownership without an approved boundary.

**Verify:** hashes, links, transcript coverage, matching skill files, Git tree, private-data exclusions and local Git status. Document failures instead of declaring compliance by assertion.
