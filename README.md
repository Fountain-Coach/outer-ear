## Project alpha

Ein kleiner Finger zeichnet Zeichen von [**Rhizoglyph**](https://rhizoglyph.jeron.org/) in **wirklichen Sand**. Die Geste wird über Reibungsgeräusche und sensorische Messungen hörbar. Ein kompakter Resonanz- oder Schwingkörper könnte auf den Sand zurückwirken; die nächste Spur trifft so auf eine bereits veränderte Oberfläche.

Angestrebt ist ein **tragbares, möglichst akkubetriebenes Instrument**, das den Sand vor Ort nutzt: **am Strand, im Sandkasten oder bei einer öffentlichen Werkstatt**. Die technische Machbarkeit ist Gegenstand der Erprobung, nicht bereits nachgewiesen. Teatro organisiert Partitur und Spielverlauf; Csound gestaltet den Klang. MIDI 2.0 und MIDI-CI können die Kommunikation und Fähigkeiten der Softwareinstrumente beschreiben. Im Vordergrund steht gemeinsames Spielen und Hören, nicht eine Technikvorführung.
